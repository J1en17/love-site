# 我们的小宇宙 🪐💞

给 TA 的恋爱纪念网站。纯原生 HTML/CSS/JS，零依赖、零构建、零框架——任何静态服务器或直接双击 `index.html` 都能打开，手机电脑都能看。

## 快速预览

```bash
# 任意静态服务器即可，例如：
cd 本目录
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

或直接双击 `index.html`（所有功能除后台备注外均可用）。

## 页面结构（6 个视图，hash 路由）

| 路由 | 页面 | 说明 |
|---|---|---|
| `#/home` | 首页 | 双头像 + 心跳 + 恋爱天数实时倒计时 + 5 入口 |

| `#/diary` | 点滴 | 日记列表：缩略图 + 日期 + 标题 + 正文 |
| `#/about` | 关于我们 | 一封写给 TA 的信，长文排版 |

## 二次编辑：只改一个文件 `js/data.js`

所有文字、日期、照片引用都集中在 `js/data.js`，带中文注释。

- **照片**：放入 `assets/photos/`，在 data.js 填文件名（如 `"first-date.jpg"`）。留 `null` 则显示粉灰占位图。
- **日期**：`loveDate: "2024-06-15"` ← 填上后首页倒计时立即开始倒数（天/时/分/秒 每秒跳动）。
- **昵称/标题/相册分组/清单/日记/信**：逐项替换 `【...】` 占位文本即可。

改完保存、刷新页面即生效。清单勾选与留言由浏览器 localStorage 记住，仅本机生效。

## 部署到公网（让 TA 也能打开）

零后端静态站，任何静态托管都行：

- **GitHub Pages**：建仓 `love-site` 推上去，Settings → Pages → 选 main 分支 /root。
- **Netlify / Vercel**：直接拖文件夹上传即部署。
- 国内可放 Gitee Pages 或云厂商对象存储 + CDN。

部署后把链接发给 TA 即可访问。

## 备注（留白设计）

- 相册/点滴/头像/音乐均为 `null` 占位，等照片和日期素材到位后二次编辑填充。
- 背景音乐：`musicFile: "song.mp3"`（mp3 放 `assets/`）即出现播放按钮。
- 留言板数据存 localStorage（仅单机可见）。如需**真正的云端留言**（所有人共享、需后台管理），需要一个小后端或现成 BaaS，需要的话告诉我，我可以接上。
- 无障碍：支持 `prefers-reduced-motion`（自动停止飘落花瓣与动画）、focus 可见、语义化标签、移动端底部导航。
